# 오늘도 안녕

같은 동네에 사는 시니어와 1인 가구가 하루 한 번 안부를 전하고, 급할 때 믿을 수 있는 이웃을 부르는 모바일 웹앱(PWA)입니다.

> 교육용 연습 프로젝트입니다. 아직 시범 단계이며, 실제 알림 발송과 여러 사람 연결은 구현되지 않았습니다.

## 지금 되는 것 (1단계, 연습용 저장소)

- **안부 체크**: 하루 한 번 "저 괜찮아요" 버튼
- **24시간 / 48시간 알림 기록**: 안부가 하루 없으면 본인 재알림, 이틀 없으면 지킴이 이웃 알림 (앱 안의 기록으로만 표시)
- **지킴이 이웃**: 최대 3명 등록, 상대가 수락해야 연결
- **이웃 SOS**: 119 안내 → 확인 단계 → 지킴이에게 도움 요청 → "가는 중" 표시
- **초대 코드 가입**: 6자리 코드가 있어야 가입
- 디자인시스템 "오늘도 안녕" 적용 (밝은 화면 / 어두운 화면)

데이터는 브라우저(localStorage) 안에만 저장되는 **연습용 가짜 저장소**입니다. (`lib/store.ts`)

## 아직 안 된 것

- 실제 푸시 알림 발송, 서버가 시간을 재서 보내는 24h/48h 자동 알림
- 여러 사람의 폰을 연결하는 서버 (Supabase 연결 예정: `supabase/schema.sql`에 DB 설계서 있음)
- 이 서비스는 의료·응급 서비스를 대체하지 않습니다. 위급하면 119에 먼저 연락하세요.

## 실행해 보기

Node.js(LTS)가 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열고, 연습용 초대 코드 `AN2611`, `AN2612`, `AN2613` 중 하나로 가입해 보세요.
폰 화면처럼 보려면 브라우저 개발자 도구(F12)에서 휴대폰 모양 아이콘을 누르세요.

## 폴더 안내

| 폴더·파일 | 설명 |
|---|---|
| `app/` | 화면 틀, 색·글자 설정(`globals.css`), 홈 화면 설치 정보(`manifest.ts`) |
| `components/` | 가입, 홈, 이웃, 알림, 내 정보, SOS 화면 |
| `lib/store.ts` | 연습용 저장소. 나중에 Supabase 호출로 바꿀 부분 |
| `supabase/schema.sql` | DB 표와 보안 규칙 설계서 |
| `public/` | 앱 아이콘, 푸시 알림용 서비스워커(`sw.js`) |
| `.env.example` | 필요한 키 이름 목록 (실제 키는 `.env.local`에만, 저장소에 올리지 않음) |

## 개인정보

비밀번호·주민등록번호·계좌번호·API 키는 코드나 저장소에 넣지 마세요. 키는 `.env.local`에만 적습니다.
